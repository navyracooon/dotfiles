## Install
HTTPS: `chezmoi init navyracooon --apply`  
SSH: `chezmoi init navyracooon --ssh --apply`

## Abstract
全体的に、シンプルで使いやすい設定を心掛けています。  
必要最小限の設定を好む人におすすめです。
